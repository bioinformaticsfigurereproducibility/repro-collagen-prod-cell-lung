# Data Information

Data was downloaded from: GEO, accession [**GSE132771**](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE132771)

Before runnning any scripts, install the required packages:

```R
source("scripts/00_install_packages.R")
```

To download data: 
``` R
source("scripts/01_download_data.R")
```
